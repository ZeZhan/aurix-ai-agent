Before you start

  • Windows x64
  • VS Code + GitHub Copilot access
  • AURIX Development Studio or AURIX Configuration Studio
  • Your target board, connected over USB

No separate Python setup. The extension provisions its runtime on first use. Internet access is needed for setup and Copilot.

  1. 01

    Install the extension

    Download the Windows VSIX. In VS Code, run Extensions: Install from VSIX... from the Command Palette and select it.

    Download for Windows x64 ↓
  2. 02

    Connect your toolchain

    Open AURIX AI in the sidebar. Select your target device, set the IDE installation path, and click Generate Copilot Config.

  3. 03

    Give Copilot a task

    Open Copilot Chat in Agent mode. Under Configure Tools, enable aurix-mcp-server. For a connected TC375 board, try:

    Create a TC375 blinky and flash it.

    Use your own device in the prompt. Review generated code and tool actions before programming hardware.

YOUR CHOICE OF AGENT

Not limited to Copilot.

The AURIX MCP server and skills are reusable beyond VS Code. Connect them to a compatible coding agent to bring the same create, build, and flash workflow to your preferred environment.

MCP server setup ↗ Browse the skills ↗
  1. 01

    Connect the AURIX MCP server

    Add the AURIX MCP server to an MCP-compatible coding agent. Provide the project folder and AURIX IDE installation path so the server's tools can find your project and local toolchain.

  2. 02

    Add skills to your workspace

    Copy our skills into the target workspace's supported skill directory. Include the project instructions they reference, and adapt client-specific tool names and instruction locations.

  3. 03

    Use the same AURIX workflow

    With workspace file access and MCP tools enabled, your agent can create or modify firmware, build with GCC, and flash with AURIX Flasher.

Client configuration and skill support vary; results depend on the agent and model. Chip-documentation search also needs the indexes bundled with the extension, which are not included in the standalone Python package.
